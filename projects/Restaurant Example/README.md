# Tide & Toast

A fictional gluten-free café and brunch concept for St. Augustine, Florida. Built as a front-end portfolio demonstration: a high-contrast coastal identity (deep navy, pale blue, oversized type), an accessible automatic food slideshow, and a mobile hamburger nav that keeps all four pages reachable without crowding the header.

**Stack:** Astro, plain CSS.

**Pages:** home, menu, about, contact.

```
pnpm --filter tide-and-toast dev
pnpm --filter tide-and-toast build
```
