# Rooted in Hope

A fictional nonprofit spring benefit landing page for "Rooted Together," built as a front-end portfolio demonstration. Turns a community garden and youth-education mission into a single scrollable page: impact numbers, an event timeline, and a clear ticket call to action, illustrated with original CSS/SVG botanical artwork rather than stock imagery.

**Stack:** Astro, plain CSS.

```
pnpm --filter rooted-in-hope dev
pnpm --filter rooted-in-hope build
```
